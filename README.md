# update-play-lib

مكتبة أندرويد عامة ومستقلة لتجريد وإدارة عمليات التحديث داخل التطبيق عبر **Google Play In-App Update API** باستخدام Kotlin Coroutines و StateFlow.

## المميزات
- دعم التحديث المرن (`Flexible`) مع بث مباشر لنسبة وحالة التحميل عبر `StateFlow<AppUpdateStatus>`.
- دعم التحديث الإجباري (`Immediate`) للشاشات والعمليات الحرجة.
- استئناف تلقائي للتحديثات التي بدأت بالفعل أو التي اكتمل تنزيلها وتنتظر التثبيت.
- مستقلة كلياً عن أي نمط واجهة (UI-Agnostic): تدعم Compose و Views.
- محرك محاكاة كامل (`FakeAppUpdateEngine`) للاختبارات ووضع التطوير دون الحاجة للاتصال الفعلي بالمتجر.
